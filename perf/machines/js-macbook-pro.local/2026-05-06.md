## Scope

Machine-scoped build and test timing for tracking local performance drift. Run with `PROFILE_MACHINE=<name> PROFILE_STAMP=YYYY-MM-DD make profile-machine` to regenerate a comparable report on another machine.

## Render Changes Under Test

- Asteroid rendering builds one visible-asteroid draw cache per frame and reuses boundary vertices for fill and outline.
- Crystal asteroid spike corners are cached per visible asteroid for the frame.
- Station ring rendering reuses per-module world positions and angles inside the same draw call.
- Hopper tractor rendering does a station-level frustum cull before module scans.
